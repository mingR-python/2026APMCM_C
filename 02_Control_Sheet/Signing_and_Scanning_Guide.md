# 控制页（承诺书）签字与扫描说明

> 文件：`Capmcm263XXXXX_ControlSheet.docx`（官方模板，复制自 zip）
> 官方要求：打印 → 全体队员签字 → 扫描 PDF 或拍照 JPG → 命名 `Capmcm<队号>cns.pdf` / `.jpg`
> **未取得全体签名 = 全队取消资格。**

---

## 1. 先填（用 Word 打开 docx，英文填写）

| 栏位 | 填什么 |
|---|---|
| Problem chosen is (A, B, C or D) | **C** |
| Team control number is (team number) | 你的 **13 位队号**（替换 `apmcm263XXXXX`） |
| School (Please fill in the full name) | 学校**英文全称**（不要缩写、不要中文） |
| Member name (Handwriting signature) 1./2./3. | 3 名队员姓名（**留空，打印后手写英文签名**） |
| Team adviser name | 指导老师姓名 |
| Date | 日期（建议提交前一天） |

> 官方提示：**fill in English**；提交后**不允许修改**；填错可能取消评奖资格。

---

## 2. 打印与签字

1. 打印填好的控制页（A4）。
2. 全体 3 名队员在 1./2./3. 处**手写英文签名**（与报名系统姓名一致）。
3. 不要代签；不要用打印体姓名代替手写签名。

---

## 3. 扫描/拍照

- 扫描为 **PDF**：`Capmcm<队号>cns.pdf`
- 或拍照为 **JPG**：`Capmcm<队号>cns.jpg`
- 要求：整页清晰、四角完整、无阴影/反光、能看清签名。
- 例：队号 `apmcm26300001` → `Capmcm26300001cns.pdf`。

---

把扫描件放回本目录：
